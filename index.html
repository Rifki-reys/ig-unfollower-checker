Cara Dapatkan File JSON Instagram

  1. Buka aplikasi Instagram > masuk ke **Profil** > menu titik tiga (kanan atas) > **Pusat Akun (Account Center)**.
  2. Pilih **Informasi dan izin Anda** > **Unduh Informasi Anda**.
  3. Klik **Minta Unduhan** > pilih **Pilih jenis informasi**.
  4. Centang opsi **Pengikut dan Mengikuti (Followers and Following)** > Klik **Berikutnya**.
  5. Ubah **Format** menjadi JSON (wajib).
  6. Ubah **Rentang Waktu** menjadi Semua waktu (All time).
  7. Klik **Kirim Permintaan**. Tunggu email dari Instagram (biasanya 5–30 menit).
  8. Download file ZIP dari email, lalu ekstrak file-nya.
  9. Cari folder `connections/followers_and_following/` untuk menemukan file `followers_1.json` dan `following.json`.
